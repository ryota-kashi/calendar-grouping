# Chrome Web Store 掲載用テキスト

---

## 拡張機能名

**Calendar Grouping**

---

## 短い説明（132文字以内）

Googleカレンダーのカレンダーをグループ単位でワンクリック切り替え。グループONでグループのみ表示、OFFで元の状態に完全復元。ポーリングなしで軽量動作。

---

## 詳細説明

```
複数のカレンダーをグループにまとめて、ワンクリックで切り替えられるChrome拡張機能です。

【こんな方におすすめ】
・チームメンバーのカレンダーをまとめて表示したい
・プロジェクトごとにカレンダーの組み合わせを切り替えたい
・採用・営業・開発など、シーンに応じてカレンダーを絞り込みたい

【主な機能】
✅ グループ管理
カレンダーを自由にグループにまとめて保存。グループの作成・編集・削除が可能です。

✅ スマートなON/OFF
グループをONにすると、グループ外のカレンダーをすべてOFFにしてグループのみを表示。グループをOFFにすると、ONにする前の状態に完全に復元します。

✅ サイドバー統合
Googleカレンダーのナビパネルに「カレンダーグループ」セクションが追加され、ページを離れずにグループを切り替えられます。

✅ 軽量・高速
定期的なポーリング（setInterval）を一切使用しないため、ブラウザへの負荷がありません。カレンダー切り替えもアニメーション遅延なしで即時反映。

✅ 自動起動
Googleカレンダーが開いていない状態でも、拡張機能アイコンをクリックすると自動でGoogleカレンダーを開きます。

【プライバシーについて】
本拡張機能はカレンダー情報をお使いのブラウザのローカルストレージにのみ保存します。外部サーバーへのデータ送信は一切行いません。
```

## スクリーンショット用キャプチャガイド

Chrome Web Storeには最低1枚、推奨5枚のスクリーンショットが必要です（1280×800 または 640×400 px）。

| # | 内容 | キャプチャ方法 |
|---|------|--------------|
| 1 | サイドバーにグループが表示されているGoogleカレンダー全体 | Googleカレンダーを開いてグループ作成後 |
| 2 | ポップアップのグループ作成画面 | 拡張機能アイコンをクリック |
| 3 | グループON時のカレンダー表示（グループのみ表示） | グループをONにした状態 |
| 4 | グループOFF時の復元（元の表示に戻る） | グループをOFFにした状態 |
| 5 | 複数グループがサイドバーに並んだ状態 | グループを3〜4個作成後 |

## 審査用補足事項（Justification）

### パーミッション使用理由

| パーミッション | 使用理由 |
|--------------|---------|
| `storage` | グループ定義・選択状態・カレンダーキャッシュをローカルに保存するため |
| `tabs` | Googleカレンダーのタブを検索し、未開の場合は自動で開くため |
| `host_permissions: calendar.google.com` | GoogleカレンダーページへのContent Script注入とメッセージ通信のため |

## 🖼️ スクリーンショット用キャプチャガイド (1280×800)

Chrome Web Storeに掲載するスクリーンショットは、推奨サイズである **1280 × 800 px** で作成することが推奨されています。

### 1. 推奨されるスクリーンショット構成（全5枚）

| # | 推奨タイトル / 内容 | 撮影する画面と状態 |
|---|---|---|
| 1 | **ワンクリックでカレンダーを切り替え**<br>(Toggle Calendars with One Click) | Googleカレンダーを開き、サイドバーに「カレンダーグループ」が表示されている全体画面。 |
| 2 | **直感的なグループ管理**<br>(Intuitive Group Management) | 拡張機能のツールバーアイコンをクリックして表示されるポップアップ画面（新規グループ追加・編集時）。 |
| 3 | **グループONで瞬時に絞り込み**<br>(Filter Instantly) | 特定のグループ（例: 「Work」や「Project A」）をONにし、関連するカレンダーのみが有効化されてカレンダー画面がスッキリしている状態。 |
| 4 | **OFFで元の表示に完全復元**<br>(Restore Original View) | グループをOFFにした際、ONにする前の個別カレンダーの選択状態が元通りに復元された状態。 |
| 5 | **複数グループの並列管理**<br>(Seamless Multi-Group Management) | 複数のグループ（例: 開発チーム、個人、営業会議など）を登録し、サイドバーに複数グループが綺麗に並んでいる状態。 |

### 2. キャプチャ撮影のポイント
* **ブラウザのUIを含めない**: ツールバーやアドレスバーなどは含めず、Googleカレンダーの表示領域（および拡張機能ポップアップ）のみを切り取ります。
* **ダミーデータの活用**: 実用的なスケジュール（「会議」「開発タスク」「ランチ」など）や、分かりやすいカレンダー名（「仕事」「プライベート」「メンバーA」など）を配置して撮影してください。
* **高コントラストなデザイン**: ダークモードやモダンな配色を活かしたキャプチャを使用すると、ストアで目を引きやすくなります。

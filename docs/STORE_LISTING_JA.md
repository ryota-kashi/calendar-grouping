# Chrome Web Store 掲載用データ（日本語 / Japanese）

このファイルは、Chrome Web Storeに拡張機能を登録する際にそのままコピー＆ペーストして使用できるテキストデータをまとめたものです。

---

## 1. 基本情報

### 拡張機能名（Extension Name）
```text
Calendar Grouping
```

### 短い説明（Summary）
*制限：132文字以内*
```text
Googleカレンダーのカレンダーをグループ単位でワンクリック切り替え。グループONでグループのみ表示、OFFで元の状態に完全復元。ポーリングなしで軽量動作。
```

### 詳細説明（Detailed Description）
*制限：16,000文字以内*
```text
複数のカレンダーをグループにまとめて、ワンクリックで切り替えられるChrome拡張機能です。

【こんな方におすすめ】
・チームメンバーのカレンダーをまとめて表示したい
・プロジェクトごとにカレンダーの組み合わせを切り替えたい
・採用・営業・開発など、シーンに応じてカレンダーを絞り込みたい

【主な機能】
✅ グループ管理
カレンダーを自由にグループにまとめて保存。グループの作成・編集・削除が可能です。

✅ スマートなON/OFF
グループをONにすると、グループ外のカレンダーをすべてOFFにしてグループのみを表示。グループをOFFにすると、ONにする前の状態に完全に復元します。

✅ サイドバー統合
Googleカレンダーのナビパネルに「カレンダーグループ」セクションが追加され、ページを離れずにグループを切り替えられます。

✅ 軽量・高速
定期的なポーリング（setInterval）を一切使用しないため、ブラウザへの負荷がありません。カレンダー切り替えもアニメーション遅延なしで即時反映。

✅ 自動起動
Googleカレンダーが開いていない状態でも、拡張機能アイコンをクリックすると自動でGoogleカレンダーを開きます。

【プライバシーについて】
本拡張機能はカレンダー情報をお使いのブラウザのローカルストレージにのみ保存します。外部サーバーへのデータ送信は一切行いません。
```

## 2. 審査用補足事項（Justification for Permissions）
*拡張機能の審査（ストア提出時）の権限使用理由の入力欄に使用します。*

### パーミッション使用理由一覧

| パーミッション | 使用理由（日本語） |
|--------------|------------------|
| `storage` | グループ定義、選択状態、および一時的なカレンダー一覧キャッシュをブラウザのローカル領域に安全に保存するため。 |
| `tabs` | 拡張機能のツールバーアイコンがクリックされた際、すでに開いているGoogleカレンダーのタブを検索し、存在しない場合は新しく自動で開くため。 |
| `host_permissions: https://calendar.google.com/*` | GoogleカレンダーのWebページ上に「カレンダーグループ」の操作UI（サイドバー）を挿入・統合し、カレンダーの表示状態を制御するためのスクリプトを安全に実行するため。 |
